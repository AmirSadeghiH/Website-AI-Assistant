نصب در کمتر از ۶۰ ثانیه

بدون build، بدون وابستگی، بدون فریم‌ورک. تنظیمات ظاهر و رفتار خودکار از سرور خوانده می‌شود.

۰۱

اسناد را آپلود کنید

PDF، TXT یا DOCX تا ۲۵ مگابایت؛ یا فقط URL سایت‌تان را بدهید تا کرال شود. پردازش در پس‌زمینه انجام می‌شود.

۰۲

ظاهر و رفتار را تنظیم کنید

رنگ، فونت، موقعیت، پیام خوش‌آمد، پیشنهادها و تم — با پیش‌نمایش زنده داخل پنل. تغییرات تا چند ثانیه روی سایت اعمال می‌شود.

۰۳

یک تگ اسکریپت جا بگذارید

کد نصب را از پنل کپی کنید و قبل از </body> سایت‌تان قرار دهید. ویجت در Shadow DOM ایزوله می‌شود و با استایل سایت شما قاطی نمی‌شود.

index.html — قبل از </body> 
<!-- AI Assistant Widget — فقط همین یک خط -->
<script
  src="https://api.example-domain.com/static/widget/widget.js"
  data-api="https://api.example-domain.com/api/chat/"
  data-widget-key="install-key-از-پنل"
  defer></script>

کلید نصب و دامنه‌ی مجاز را از پنل ثبت می‌کنید — تا چند ثانیه بعد روی API و CORS اعمال می‌شوند.

امنیت، بخشی از محصول است — نه آپشن

۱۰۸ تست خودکار — از گارد SSRF کرالر تا ضد ZIP/XML bomb و گارد secret-scan — در هر نسخه اجرا می‌شوند.

رمزنگاری کلیدها در DB

کلیدهای LLM فقط روی سرور و رمزنگاری‌شده (Fernet) — هرگز به مرورگر نمی‌رسند.

گارد SSRF کرالر

IPهای خصوصی و loopback رد می‌شوند؛ ریدایرکت‌ها دوباره اعتبارسنجی می‌شوند.

Allowlist دامنه

فقط دامنه‌های مجازِ شما می‌توانند از API استفاده کنند + throttling چندلایه.

توکن HMAC مکالمه

تاریخچه و بازخورد هر مکالمه فقط با توکن امضاشده‌ی همان مکالمه باز می‌شود.

بدون XSS — Shadow DOM

ویجت ایزوله است؛ Markdown محدود و امن، متن‌ها escape و لینک‌های مخرب فیلتر می‌شوند.

ضد ZIP/XML Bomb

محدودیت حجم و ساختار فایل + defusedxml + sniff محتوا قبل از پردازش هر سند.

ضداسپم فرم‌ها

Honeypot نامرئی + سقف نرخ جداگانه برای سرنخ و ارجاع انسانی.

محافظت از Prompt Injection

پرامپت سیستمی صریحاً دستورهای داخل اسناد را خنثی می‌کند + گارد secret-scan در تست‌ها.

سوالات متداول

قبل از شروع، بدانید

کمتر از 60 ثانیه زمانِ خواندن اسکریپت لازم است؛ کل فرایند — آپلود اسناد، تنظیم ظاهر و کپی تگ اسکریپت — با ویزارد 6 مرحله‌ای پنل معمولاً زیر 10 دقیقه تمام می‌شود. هیچ سروریز یا تغییر کد سایت لازم نیست.

موتور RAG فقط از اسناد و صفحات کرال‌شده‌ی خودِ شما جواب می‌سازد و منبع هر پاسخ را نشان می‌دهد (Citations). اگر پاسخی در دانش نباشد، مدل حدس نمی‌زند: صادقانه اعلام می‌کند و گزینه‌ی اتصال به کارشناس انسانی را نشان می‌دهد.

هر API سازگار با OpenAI — مدل پاسخ‌دهنده، مدل embedding، Base URL، کلید، تایم‌اوت و محدودیت توکن همگی از پنل قابل تغییرند و کلیدها رمزنگاری‌شده در دیتابیس نگه‌داری می‌شوند.

کلیدها هرگز به مرورگر نمی‌رسند؛ دسترسی API با allowlist دامنه و throttling چندلایه کنترل می‌شود؛ تاریخچه‌ی مکالمه‌ها با توکن HMAC محافظت می‌شود و کرالر گارد SSRF دارد. مدل امنیتی کامل محصول مستند و با ۱۰۸ تست خودکار پوشش داده شده است.

کش پاسخ و کش معنایی سؤالات پرتکرار را اصلاً به LLM نمی‌رسانند؛ همزمانی LLM با semaphore و پاسخ ۴۲۹ استاندارد کنترل می‌شود است.
