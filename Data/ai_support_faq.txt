# AI Support Platform — سوالات متداول و راهنمای جامع

## معرفی محصول

### AI Support Platform چیست؟
AI Support Platform یک پلتفرم آماده فروش برای افزودن دستیار هوشمند پشتیبانی مبتنی بر هوش مصنوعی (RAG) به سایت مشتریان است. مشتری فقط یک تگ اسکریپت ساده در سایت خود قرار می‌دهد و دستیار هوشمند بلافاصله فعال می‌شود. این دستیار بر اساس اسناد و اطلاعات واقعی کسب‌وکار مشتری پاسخ می‌دهد و هیچ‌چیز را حدس نمی‌زند.

### این محصول برای چه کسانی مناسب است؟
برای هر کسب‌وکاری که وب‌سایت دارد و می‌خواهد پشتیبانی مشتریان را هوشمند کند. شامل فروشگاه‌های آنلاین، شرکت‌های خدماتی، بانک‌ها، بیمه‌ها، مراکز آموزشی و هر سازمانی که سوالات تکراری زیادی از مشتریان دریافت می‌کند.

### فرق AI Support با چت‌بات‌های معمولی چیست؟
چت‌بات‌های معمولی فقط روی جریان‌های از پیش تعریف‌شده کار می‌کنند. AI Support از تکنولوژی RAG (Retrieval-Augmented Generation) استفاده می‌کند یعنی اسناد و اطلاعات واقعی شما را می‌خواند و بر اساس آن‌ها پاسخ دقیق تولید می‌کند. این یعنی پاسخ‌ها همیشه به‌روز و معتبر هستند.

## نصب و راه‌اندازی

### نصب ویجت روی سایت چقدر طول می‌کشد؟
کمتر از ۳ ثانیه. فقط کافی است یک تگ اسکریپت قبل از برچسب بسته شدن body سایت خود قرار دهید. نیازی به نصب هیچ افزونه یا فریمورکی نیست.

### آیا برای نصب ویجت نیاز به توسعه‌دهنده دارم؟
خیر. هر کسی که بتواند یک تگ اسکریپت در سایت خود قرار دهد می‌تواند ویجت را نصب کند. فقط یک خط کد کپی-پیست می‌شود.

### آیا ویجت روی موبایل هم کار می‌کند؟
بله. ویجت کاملاً ریسپانسیو است و در موبایل به‌صورت تمام‌صفحه نمایش داده می‌شود. این قابلیت از تنظیمات پنل ادمین قابل تغییر است.

### ویجت روی چه مرورگرهایی کار می‌کند؟
روی تمام مرورگرهای مدرن包括 Chrome, Firefox, Safari, Edge کار می‌کند. از تکنولوژی Shadow DOM استفاده می‌کند که تداخلی با استایل‌های سایت مشتری ایجاد نمی‌کند.

### آیا ویجت روی سایت‌های HTTPS و HTTP کار می‌کند؟
بله. ولی توصیه اکید می‌شود که سایت مشتری از HTTPS استفاده کند تا امنیت ترافیک تضمین شود.

## مدیریت اسناد

### چه فرمت‌هایی پشتیبانی می‌شوند؟
PDF، TXT (متنی) و DOCX (Word). حداکثر حجم هر فایل ۲۵ مگابایت است.

### چگونه اسناد را آپلود کنم؟
از پنل ادمین Django به بخش Knowledge Documents بروید و فایل را آپلود کنید. سپس دکمه «شروع پردازش و ساخت embedding» را بزنید. پردازش در پس‌زمینه انجام می‌شود.

### آیا می‌توانم اسناد را حذف یا جایگزین کنم؟
بله. از پنل ادمین می‌توانید هر سند را حذف یا ویرایش کنید. با حذف یک سند، embedding‌های مرتبط نیز به‌صورت خودکار حذف می‌شوند.

### پردازش یک سند چقدر طول می‌کشد؟
بسته به حجم فایل و تعداد صفحات، معمولاً بین ۱۰ ثانیه تا ۲ دقیقه طول می‌کشد. پردازش در پس‌زمینه انجام می‌شود و نیازی به منتظر ماندن نیست.

### آیا می‌توانم همزمان چند سند را پردازش کنم؟
بله. می‌توانید چند سند را انتخاب کنید و Action «شروع پردازش و ساخت embedding» را اجرا کنید. اسناد به‌صورت ترتیبی پردازش می‌شوند.

## تنظیمات ظاهری

### آیا می‌توانم رنگ و ظاهر ویجت را تغییر دهم؟
بله. از پنل ادمین می‌توانید رنگ اصلی، رنگ ثانیه، گرادیان، اندازه، فونت، موقعیت، لوگو، پیام خوش‌آمد و پیشنهادات را تنظیم کنید. همه چیز بعد از ذخیره حداکثر ۱۰ ثانیه بعد روی سایت اعمال می‌شود.

### آیا می‌توانم ویجت را در سمت چپ سایت قرار دهم؟
بله. از بخش تنظیمات ویجت در پنل ادمین، موقعیت را روی «Bottom left» تنظیم کنید.

### آیا می‌توانم پیام خوش‌آمد را تغییر دهم؟
بله. از بخش Widget Settings در پنل ادمین، فیلد Greeting را ویرایش کنید. می‌توانید ایموجی و فارسی بنویسید.

### آیا می‌توانم لینک‌های FAQ و Privacy را اضافه کنم؟
بله. در بخش پروفایل کسب‌وکار در Widget Settings، فیلدهای FAQ URL و Privacy URL را پر کنید. لینک‌ها در پایین ویجت نمایش داده می‌شوند.

## امنیت

### آیا کلیدهای API من امن هستند؟
بله. کلیدهای API مدل‌های هوش مصنوعی با الگوریتم Fernet و کلید مشتق‌شده از SECRET_KEY رمزنگاری می‌شوند و فقط به‌صورت رمزنگاری‌شده در پایگاه داده ذخیره می‌شوند. هرگز به مرورگر کاربر ارسال نمی‌شوند.

### آیا سایت‌های دیگر می‌توانند از API من استفاده کنند؟
خیر. با تنظیم کلید نصب ویجت و لیست دامنه‌های مجاز، فقط سایت‌های مجاز اجازه استفاده از API را دارند. علاوه بر آن rate limiting نیز فعال است.

### ویجت در برابر XSS امن است؟
بله. ویجت از Shadow DOM استفاده می‌کند که ایزوله است و تمام متن‌های کاربر escape می‌شوند. فقط Markdown محدود (bold, italic, link, list) پشتیبانی می‌شود.

### آیا فایل‌های مخرب (ZIP bomb, XML bomb) فیلتر می‌شوند؟
بله. سیستم فایل‌های DOCX را قبل از پردازش بررسی می‌کند: محدودیت تعداد بخش‌ها، محدودیت حجم بازشده، و استفاده از defusedxml برای جلوگیری از حملات entity expansion.

### آیا admin panel امن است؟
بله. در Production: SECRET_KEY اجباری، CSRF فعال، session cookie secure، rate limiting روی لاگین ادمین، و HTTPS اجباری.

## عملکرد و مقیاس‌پذیری

### این سیستم چند کاربر هم‌زمان را پشتیبانی می‌کند؟
حداقل ۲۰۰ کاربر هم‌زمان. با استفاده از PostgreSQL و Redis در Production، ۴ worker و ۲۴ thread در gunicorn و semaphore محدودکننده همزمانی LLM.

### اگر سوالات تکراری زیادی بیاید چه؟
پاسخ‌های تکراری (بدون history) به‌صورت خودکار کش می‌شوند (پیش‌فرض ۶۰ ثانیه). این باعث می‌شود در لحظات پیک، بسیاری از درخواست‌ها بدون فراخوانی LLM پاسخ داده شوند.

### اگر صف LLM پر شود چه اتفاقی می‌افتد؟
درخواست‌های مازاد فوراً با کد 429 و پیام «The assistant is busy» پاسخ داده می‌شوند. ویجت به‌صورت خودکار دوباره تلاش می‌کند. هیچ درخواستی روی صف بی‌نهایت گیر نمی‌کند.

### آیا سیستم از Redis پشتیبانی می‌کند؟
بله. برای Production توصیه می‌شود از Redis برای کش و rate limiting اشتراکی بین workerها استفاده شود.

## قیمت‌گذاری و پشتیبانی

### آیا نسخه رایگان دارید؟
نسخه Open Source پروژه در GitHub موجود است. برای استفاده تجاری و پشتیبانی حرفه‌ای با ما تماس بگیرید.

### چه مدل‌های هوش مصنوعی پشتیبانی می‌شوند؟
هر API سازگار با OpenAI شامل DeepSeek, GPT-4, Claude, Gemini و مدل‌های فارسی. مدل‌ها از پنل ادمین قابل تنظیم هستند.

### آیا می‌توانم از مدل‌های مختلف برای LLM و Embedding استفاده کنم؟
بله. LLM (مدل پاسخ‌دهنده) و Embedding (مدل تبدیل متن به بردار) مستقل هستند و هر کدام از پنل ادمین قابل تنظیم هستند.

### آیا امکان مدیریت چند مشتری از یک پنل وجود دارد؟
بله. هر مشتری یک کلید نصب و لیست دامنه‌های مجاز مخصوص به خود دارد. شما فقط از یک پنل ادمین همه مشتریان را مدیریت می‌کنید.

## عیب‌یابی

### ویجت روی سایت مشتری کار نمی‌کند
۱. دامنه سایت مشتری را در بخش «نصب ویجت و کنترل دسترسی» پنل ادمین ثبت کنید.
۲. کلید نصب ویجت را تنظیم کنید و مطمئن شوید data-widget-key در تگ اسکریپت صحیح است.
۳. مطمئن شوید سایت مشتری از HTTPS استفاده می‌کند.

### پاسخ‌ها دقیق نیستند
۱. اسناد بیشتری آپلود و پردازش کنید.
۲. سوالات دقیق‌تری بپرسید.
۳. system prompt و user prompt را در Widget Settings بهینه‌سازی کنید.

### پاسخ‌ها خیلی کندند
۱. LLM_MAX_RETRIES را روی ۰ تنظیم کنید.
۲. کش پاسخ را بالا ببرید (RAG_RESPONSE_CACHE_SECONDS).
۳. مدل سبک‌تری انتخاب کنید.

### خطای corpus_config دریافت می‌کنم
مدل Embedding تغییر کرده است. همه اسناد را دوباره پردازش کنید (Action «ساخت embedding» روی هر سند).

### همه کاربران همزمان خطای 429 می‌گیرند
پشت reverse proxy هستید. مطمئن شوید TRUST_X_FORWARDED_FOR=True است و nginx هدر X-Forwarded-For را بازنویسی می‌کند.

## تفاوت با رقبا

### AI Support چه تفاوتی با ChatGPT Widget دارد؟
ChatGPT Widget مستقیماً از مدل OpenAI استفاده می‌کند و اطلاعات اختصاصی کسب‌وکار شما را ندارد. AI Support از RAG استفاده می‌کند یعنی اسناد شما را می‌خواند و بر اساس آن‌ها پاسخ دقیق تولید می‌کند. همچنین کلید API شما هرگز به مرورگر کاربر نمی‌رسد.

### آیا نیاز به دانش فنی برای استفاده دارم؟
خیر. تمام تنظیمات از پنل ادمین Django انجام می‌شود. فقط نصب اولیه و آپلود اسناد نیاز به چند کلیک ساده دارد.

### آیا ویجت فارسی‌بومی است؟
بله. ویجت با کاملترین پشتیبانی از فارسی ساخته شده: راست‌چین خودکار، فونت فارسی، و ریسپانسیو کامل.
